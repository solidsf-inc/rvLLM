Audit boundary

Scope, reproduction, and Vast.ai verification

Schedule synthesis and roofline evaluations run deterministically on any host via rvllm_ptx_tuner; hardware execution and ptxas zero-spill verification run on leased Vast.ai GPUs via scripts/vast_ptx_tuner.py.

Analytical vs. hardware

The 9-architecture table above reports the deterministic 1,000D × 100W micro-architectural roofline model used during schedule synthesis. Hardware claims require executing the emitted vast_work_units.json on the target SM via scripts/vast_ptx_tuner.py --live-vast.

MatchedPair & policy pin

Every winning schedule is serialized into autotune.policy.<arch>.json with a 64-hex SHA-256 sidecar and validated through rvllm_cutlass::Policy::validate() before bundle emission.

Reproduction

Run cargo run --release --locked --manifest-path v3/Cargo.toml -p rvllm-cutlass --bin rvllm_ptx_tuner or see docs/ptx-ultra-tuner.md.
